# Arcade Mania

Ez itt az **Arcade Mania** projekt **Adatbázisának** github oldala. 

---

A projekt frontend-jével kapcsolatos összes dokumentum ezen a github oldalon található meg. Ezek egész pontosan a következők: React frontend és a hozzá kapcsolódó tesztek + egy Python Selenium webdriver teszt.

A React teljes mértékben működőképes, miután telepítettük a bun-t (persze ehhez szükség van az adatbázis és a webAPI megfelelő működésére is)
